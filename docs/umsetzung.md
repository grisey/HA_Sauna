# Funktionsstand und technische Orientierung

Die aktuelle Funktionsbeschreibung steht in der [Bedienungsanleitung](bedienung.md).
Der verbindliche Ablauf ist in [Betrieb](betrieb.md) zusammengefasst; die
[Architektur](architektur.md) ordnet ihn den technischen Bausteinen zu.

Welche Prüfungen tatsächlich ausgeführt werden und was sie nachweisen, beschreibt
[Prüfstand](abnahme.md). Das Ergebnis jedes Commits ist dort verlinkt. Für die
Installation über HACS gilt die [Einrichtungsanleitung](einrichtung.md).

Frühere Zwischenstände und Prüfprotokolle sind in der Git-Historie erhalten.
